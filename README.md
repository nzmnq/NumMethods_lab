# Чисельні методи — Лабораторна робота №2

**Тема:** Методи уточнення коренів нелінійних рівнянь  
**Варіант:** 8 (Група 2)  
**Метод:** Метод січних  
**Рівняння:** $e^x + x = 0$, проміжок $[-2; 3]$  
**Точність:** $\varepsilon = 0.1\%$

## Опис
Програма реалізує ітераційний метод січних для знаходження кореня нелінійного рівняння. Замість обчислення аналітичної похідної використовується її різницеве наближення за двома попередніми точками.

## Компіляція та запуск
```bash
g++ src/main.cpp -o src/main.exe
./src/main.exe
```

```text
ітерація: 5
x = -0.567143
похибка: 0.0018087
кінцеве зн корення: -0.567143

```
