# Чисельні методи — Лабораторна робота №1

**Тема:** Прямі та ітераційні методи розв’язування систем лінійних алгебричних рівнянь  
**Варіант:** 8  
**Метод:** Метод Гауса з вибором головного елемента по всій матриці  
**Завдання:** Обчислення визначника квадратної матриці 4×4 (Матриця №1)

## Опис
Програма реалізує прямий хід методу Гаусса з повним вибором головного елемента (по всій підматриці). На кожному кроці шукається найбільший за модулем елемент, виконуються перестановки рядків і стовпців із відповідною зміною знаку визначника, після чого матриця зводиться до трикутного вигляду.

## Компіляція та запуск
```bash
g++ src/main.cpp -o src/main.exe
./src/main.exe
```

```text
Визначник матриці: 442.0670
```
